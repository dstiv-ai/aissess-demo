# Aissess · public demonstration

[Open the two-minute demo](https://dstiv-ai.github.io/aissess-demo/).

A teacher-led assessment workspace: control classroom access, carry student writing across lessons, and review suggestions before releasing feedback.

This repository contains only the built static demo. Every learner, response, result and class is fictional. Marking suggestions are prepared examples; the quiz uses a fixed answer key. No sign-in, paid AI calls, or application backend is used. Changes stay in the visitor's browser and can be cleared with Reset demo.

Designed and built by Dimitrios Stivaktas.
